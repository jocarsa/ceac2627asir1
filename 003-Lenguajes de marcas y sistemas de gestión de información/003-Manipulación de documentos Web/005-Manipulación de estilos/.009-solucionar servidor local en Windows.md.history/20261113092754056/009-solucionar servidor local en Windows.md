Descargamos XAMPP
X = Cualquier sistema
A = Apache
M = MySQL
P = PHP
P = Perl

https://www.apachefriends.org/es/index.html

Cuando hayáis descargado el instalador, instaláis con todo "siguiente"
Una vez instalado, abrís el "panel de control de XAMPP", y arrancáis SOLO Apache

Una vez que hayáis hecho esto:
Todo el contenido que deseáis ejecutar debéis ponerlo en 
C:/xampp/htdocs

Si la carpeta se llama C:/xampp/htdocs/JoseVicente/index.html
En el navegador se llama http://localhost/JoseVicente/index.html

Esto quiere decir que C:/xampp/htocs equivale a http://localhost
